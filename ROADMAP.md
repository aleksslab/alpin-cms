# AlPin CMS — Roadmap

Планы развития AlPin CMS — flat-file CMS на PHP без базы данных.

Формат — статус (`planned` / `in progress` / `done`) и версия, в которой пункт вышел или выйдет.

Версионирование — [SemVer](https://semver.org/lang/ru/): `v1.2.0` → `v1.2.1` (патч) → `v1.3.0` (минор) → `v2.0.0` (мажор).

## Ближайшее

### Контент

- **Планирование публикации** — 4 статуса (`draft` / `scheduled` / `published` / `archived`), поля `publish_at` / `unpublish_at`, cron-публикация. — `done (v1.3.0)`. В версии v2.0.0 cron-публикация (задача `publish`) вынесена в плагин `publish`.
- **История изменений** — снапшоты страниц при сохранении, откат на любую версию, дедупликация, лимит версий, `data/history/`. — `done (v1.7.0)`. В версии v2.0.0 вынесена в плагин `history`.
- **Корзина / мягкое удаление** — `data/trash/`, восстановление в один клик, ручная очистка (без автоочистки). — `done (v1.4.0)`. В версии v2.0.0 вынесена в плагин `trash`.
- **Превью черновика по секретной ссылке** — временный preview из конструктора + постоянная preview-ссылка для согласования. — `done (v1.5.0)`. В версии v2.0.0 вынесен в плагин `preview`.

### Плагины

- **Обратный звонок** (плагин `callback`) — плавающая кнопка и мини-форма: настройки внешнего вида, e-mail получателя, антиспам, журнал заявок. — `planned (следующее)`
- **Поиск по сайту** (плагин `search`) — flat-file индекс `data/search_index.json`, маршрут `/search?q=`, переиндексация при сохранении и удалении страницы, собственная вкладка в админке. — `planned (следующее)`

### SEO

- **Автогенерация `sitemap.xml` и `robots.txt`** — из `data/pages/`, крон, UI, автообновление. — `done (v1.6.0)`. В версии v2.0.0 вынесены в плагин `seo-tools`.
- **301-редиректы при смене slug** — `slug_history` в JSON, автоматические редиректы. — `done (v1.6.0)`

### Медиа

- **WebP при загрузке** — автогенерация `.webp` рядом с jpg/png, подмена `src` на фронте через `mediaImageSrc()`, кнопка «Удалить все .webp», конвертация существующих. — `done (v1.8.0)`. В версии v2.0.0 вынесены в плагин.
- **Lazy loading** — `loading="lazy"` + `decoding="async"` для контентных изображений (кроме hero, карусели, логотипа в хедере). — `done (v1.8.0)`
- **AVIF** — конвертация в `.avif` (если PHP 8.1+ и GD/Imagick с AVIF). — `planned`
- **Респонсив-версии изображений** — `image-320.webp`, `image-640.webp`, `srcset` в модулях. — `planned`

### Система

- **Плагины** — архитектура, установка, управление. — `done (v2.0.0)`
- **Логи системы** — фильтры, поиск, ротация. — `done (v2.0.0)`. Настройки вынесены в плагин `logs`.
- **Вкладка «Документация»** — README установленных плагинов и файлы из `docs/` в админке, собственный Markdown-рендерер. — `done (v2.1.0)`
- **Сворачивание левого сайдбара** — колонка с иконками, состояние в `localStorage`. — `done (v2.1.0)`
- **Проверка `sha256` архивов каталога** — сверка ZIP после скачивания. — `done (v2.1.0)`
- **Клиентское кеширование статики** — годовой `immutable` для CSS/JS/шрифтов с `?v=filemtime`, `mod_deflate`. — `done (v2.1.0)`
- **Почтовый агент (SMTP)** — секция «Почта» в настройках сайта, конфиг в `config/data/mail_config.json`, пароль шифруется, тестовое письмо, скрытие форм без настроенного агента. — `done (не выпущено)`
- **Общие хелперы шифрования** — `cms_encrypt_secret()` / `cms_decrypt_secret()` в ядре, перевод `backups` на них. — `done (не выпущено)`

## Среднесрочное

- **Режим «Технические работы»** — 503 + кастомная страница + `?bypass=token`, автоснятие по дате, таймер. — `done (v1.9.0)`. В версии v2.0.0 вынесен в плагин `maintenance`.
- **Медиатека с тегами и поиском** — `planned`
- **Тёмная тема на фронте** — `done (v1.10.0)`. В версии v2.0.0 вынесена в плагин `dark-theme`.
- **REST API (read-only)** — `planned`

## Идеи

Идеи — то, что обсуждается, но не имеет ни версии, ни сроков. Может быть реализовано, может быть отброшено.

- **Экспорт/импорт страницы с зависимостями** — JSON + список требуемых модулей и версий. — `idea`
- **Cookie-баннер** — простой баннер (плагин `cookie-banner`) — `done`. Полноценный GDPR-менеджер `cookie-consent` — `done (v2.1.0)`.
- **Хлебные крошки** — автогенерация из меню. — `done (v1.11.0)`
- **Блог** — отдельный модуль + RSS/Atom. — `idea`
- **Каталог модулей и плагинов** — `catalog.json` + ZIP, установка и обновление из админки. — `done (v2.0.0)`. Публичный маркетплейс с публикацией от сообщества — `idea`.
- **Мультиязычность** — `idea`
