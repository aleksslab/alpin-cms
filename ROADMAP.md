# AlPin CMS — Roadmap

Планы развития AlPin CMS — flat-file CMS на PHP без базы данных.

Формат — статус (`planned` / `in progress` / `done`) и версия, в которой пункт вышел или выйдет.

Версионирование — [SemVer](https://semver.org/lang/ru/): `v1.2.0` → `v1.2.1` (патч) → `v1.3.0` (минор) → `v2.0.0` (мажор).

## Ближайшее

### Контент

- **Планирование публикации** — 4 статуса (`draft` / `scheduled` / `published` / `archived`), поля `publish_at` / `unpublish_at`, cron-публикация. — `done (v1.3.0)`
- **История изменений** — снапшоты страниц при сохранении, откат на любую версию, дедупликация, лимит версий, `data/history/`. — `done (v1.7.0)`
- **Корзина / мягкое удаление** — `data/trash/`, восстановление в один клик, ручная очистка (без автоочистки). — `done (v1.4.0)`
- **Превью черновика по секретной ссылке** — временный preview из конструктора + постоянная preview-ссылка для согласования. — `done (v1.5.0)`

### SEO

- **Автогенерация `sitemap.xml` и `robots.txt`** — из `data/pages/`, крон, UI, автообновление. — `done (v1.6.0)`
- **301-редиректы при смене slug** — `slug_history` в JSON, автоматические редиректы. — `done (v1.6.0)`

### Медиа

- **Конвертация в WebP / AVIF при загрузке** — оригинал сохраняем, отдаём `<picture>` с фолбэком. — `planned`
- **Респонсив-версии изображений** — `image-320.webp`, `image-640.webp`, `srcset` в модулях. — `planned`
- **Ленивая загрузка** — `loading="lazy"` + `decoding="async"` централизованно во всех модулях. — `planned`

## Идеи

Идеи — то, что обсуждается, но не имеет ни версии, ни сроков. Может быть реализовано, может быть отброшено.

- **Экспорт/импорт страницы с зависимостями** — JSON + список требуемых модулей и версий. — `idea`
- **Поиск по сайту** — flat-file индекс `data/search_index.json`. — `idea`
- **Cookie-баннер** — GDPR-friendly, с настройками analytics / marketing. — `idea`
- **Хлебные крошки** — автогенерация из меню. — `idea`
- **Виджет «Обратный звонок»** — плавающая кнопка + mini-форма. — `idea`
- **Блог** — отдельный модуль + RSS/Atom. — `idea`
- **Маркетплейс модулей** — `idea`
- **Мультиязычность** — `idea`
