# Как помочь проекту

Спасибо за интерес к AlPin CMS! 🎉

## 🐛 Сообщить о баге

1. **Проверь** [Issues](https://github.com/AlekSSLab/alpin-cms/issues) — **может**, **уже** **есть**.
2. **Создай** **новый** **issue** **с** **меткой** `bug`.
3. **Приложи:**
   - **Версию** **PHP** (**`php -v`**).
   - **Версию** **CMS**.
   - **Шаги** **воспроизведения**.
   - **Скриншот**/**лог** **ошибки**.
   - **Ожидаемое** **поведение**.
   - **Фактическое** **поведение**.

## 💡 Предложить улучшение

1. **Проверь** [Issues](https://github.com/AlekSSLab/alpin-cms/issues) — **может**, **уже** **обсуждается**.
2. **Создай** **issue** **с** **меткой** `enhancement`.
3. **Опиши:**
   - **Что** **предлагаешь**.
   - **Зачем** **это** **нужно**.
   - **Как** **реализовать** (**если** **есть** **идеи**).

## 🔧 Pull Request

### Процесс

1. **Форкни** **репозиторий**.
2. **Создай** **ветку** **от** `main`:
   ```bash
   git checkout -b feature/my-feature
   ```
3. **Внеси** **изменения**.
4. **Проверь** **по** **чек-листу** **ниже**.
5. **Закоммить** (**формат** `feat:`, `fix:`, `sec:`):
   ```bash
   git commit -m "feat: добавил новый модуль quote"
   ```
6. **Запушь**:
   ```bash
   git push origin feature/my-feature
   ```
7. **Создай** **PR** **с** **описанием**.

### Чек-лист перед PR

- [ ] **Код** **соответствует** **стандартам** (см. [docs/for-developers/SECURITY.md](docs/for-developers/SECURITY.md)).
- [ ] **PHP 7.4+** — **без** `match()`, **без** **named** **args**.
- [ ] **Все** **функции** **с** **PHPDoc**.
- [ ] **JS** — **IIFE** + **`readyState`**.
- [ ] **POST-обработчики** — **CSRF-проверка**.
- [ ] **Вывод** — `e()`, **URL** — `safeUrl()`.
- [ ] **HTML** — `validateHtml` + `sanitizeHtml`.
- [ ] **Новые** **файлы** **данных** — **в** `data/` **с** `.htaccess`.
- [ ] **Протестировано** **на** **PHP 7.4** **и** **8.3**.
- [ ] **Обновлён** `CHANGELOG.md`.

### Стиль кода

**PHP:**
- **Отступ:** 4 пробела.
- **Скобки:** `function foo() {` (**K&R**).
- **Типизация:** `function foo(string $x, array $y = []): array`.
- **Комментарии:** PHPDoc.

**JS:**
- **Отступ:** 4 пробела.
- **IIFE** **для** **модулей**.
- **`'use strict'`**.

### Названия коммитов

| Префикс | Что |
|---------|-----|
| `feat:` | Новая **функциональность** |
| `fix:` | Исправление **бага** |
| `sec:` | Улучшение **безопасности** |
| `docs:` | Документация |
| `refactor:` | Рефакторинг **без** **изменения** **поведения** |
| `perf:` | Производительность |
| `chore:` | Рутина (**зависимости**, **CI**) |

**Пример:**
```
sec: добавил validateHtml для поля name

Предотвращает XSS через settings.json.
См. docs/for-developers/SECURITY.md.
```

## 🧪 Тестирование

**Перед** **PR** **проверь:**

### 1. Синтаксис

```bash
find . -name "*.php" -exec php -l {} \;
```

**Ожидание:** `No syntax errors`.

### 2. Ручное тестирование

- **Логин**/**логаут**.
- **Создание**/**редактирование**/**удаление** **страницы**.
- **Работа** **конструктора**.
- **Сохранение** **настроек**.
- **Установка**/**удаление** **модуля**.
- **Создание** **бэкапа**.

### 3. Совместимость

**Если** **есть** **возможность** — **прогони** **на** **PHP 7.4** **и** **8.3**.

## 📄 Лицензия вклада

Отправляя Pull Request, вы соглашаетесь, что ваш вклад 
распространяется под той же лицензией **GPL v3**, что и проект.

Это означает:
- Ваш код будет открытым.
- Любой может использовать его (в т.ч. коммерчески).
- Производные работы должны оставаться открытыми под GPL v3.
