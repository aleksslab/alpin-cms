# Разработка модулей

Модуль в AlPin CMS — это **ZIP-архив** с **manifest.json** в корне и набором
файлов для **админки** (`admin/`) и **сайта** (`site/`). После установки
файлы распаковываются в общие папки CMS.

## 📦 Структура ZIP

```
my-module.zip
├── manifest.json           # Метаданные (обязательно)
├── preview.png             # Превью 200×200 (опционально)
│
├── admin/                  # Форма настроек в админке
│   ├── module.php          # Форма (обязательно, если has_settings=true)
│   ├── style.css           # Стили формы (опционально)
│   └── script.js           # JS формы (опционально)
│
└── site/                   # Рендеринг на фронте
    ├── module.php          # Рендер (обязательно)
    ├── style.css           # Стили (опционально)
    └── script.js           # JS (опционально)
```

### Куда что распаковывается

| Из ZIP | Куда попадает | Как используется |
|--------|---------------|------------------|
| `admin/module.php` | `config/modules/{id}/module.php` | Форма в модалке настроек |
| `admin/style.css` | `config/modules/{id}/style.css` | Стили формы (только в админке) |
| `admin/script.js` | `config/modules/{id}/script.js` | JS формы (только в админке) |
| `site/module.php` | `modules/{id}.php` | Рендер на фронте |
| `site/style.css` | `css/{id}.css` | Стили на фронте |
| `site/script.js` | `js/{id}.js` | JS на фронте |

**Ключевое:**
- Файлы `admin/*` живут **в папке модуля в админке**, имя сохраняется.
- Файлы `site/*` **переименовываются в `{id}.{ext}`** и кладутся в **общие** `css/`, `js/`, `modules/`.
  - `my-module` → `css/my-module.css`, `js/my-module.js`, `modules/my-module.php`.
- **Не давай** `site/module.php` имя, отличающееся от `id`. Иначе **файлы не найдутся**.
- **Дубликаты `style.css`** между модулями **исключены**, потому что имя = id.

## 📄 `manifest.json`

**Обязательные** поля:

```json
{
    "id": "my-module",
    "name": "Мой модуль",
    "icon": "icon-box",
    "description": "Краткое описание модуля",
    "version": "1.0.0",
    "author": "Ваше имя",
    "has_settings": true,
    "auto_unpack": false
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | **Уникальный ID** (`a-z`, `0-9`, `-`, `_`). Используется в именах файлов. |
| `name` | string | Название в админке. |
| `icon` | string | Lucide-класс (`icon-box`, `icon-star`, ...). |
| `description` | string | Короткое описание. |
| `version` | string | Semver-версия. |
| `author` | string | Автор. |
| `has_settings` | bool | Есть ли форма настроек. Если `false` — модуль без настроек, `admin/module.php` не нужен. |
| `auto_unpack` | bool | **См. «Распаковка модуля» ниже.** |

### Валидация при загрузке

- `id` — только `[a-z0-9\-_]+`, регистр **важен** (нижний).
- Размер ZIP — не более **10 МБ**.
- `manifest.json` — **в корне** ZIP.
- Защита от **ZIP Slip** — пути с `..`, `/`, `C:\`, NUL-байты **блокируются**.

## 🚀 Установка модуля

### Через админку

1. **Управление модулями** → **Установить модуль**.
2. Перетащи ZIP.
3. Дождись распаковки.
4. Модуль появится в списке.
5. **Добавь на страницу** через конструктор.

### Распаковка модуля — `auto_unpack`

От флага `auto_unpack` зависит, **когда** модуль распакуется из ZIP в общие папки.

| `auto_unpack` | Поведение |
|---------------|-----------|
| `true` | Распаковывается **сразу при установке**. Быстрее для пользователя, но **загрязняет папки** сразу после загрузки, даже если модуль не будет использован. |
| `false` | Распаковывается **при первом добавлении** на страницу через конструктор. Либо **при обновлении** — если модуль уже где-то используется. |

**Что выбрать:**
- **`true`** — если модуль **точно** будет использоваться (например, встроенный).
- **`false`** — если модулей **много**, и ты не хочешь **держать в папках** все неиспользуемые.

### Вручную (для разработки)

**Не рекомендуется для прода** — при обновлении версии вручную надо чистить каждый файл. Для разработки:

1. Создай структуру:
   ```
   config/modules/my-module/
   ├── module.php          # форма настроек
   ├── style.css           # стили формы
   └── script.js           # JS формы

   modules/my-module.php   # рендер на фронте
   css/my-module.css       # стили фронта (опционально)
   js/my-module.js         # JS фронта (опционально)
   ```

2. Добавь запись в `config/data/modules.json`:
   ```json
   {
       "my-module": {
           "name": "Мой модуль",
           "icon": "icon-box",
           "description": "Описание",
           "has_settings": true,
           "auto_unpack": true,
           "version": "1.0.0",
           "author": "Вы"
       }
   }
   ```

3. Очисти кеш в админке (Настройки → Кеширование страниц → Очистить весь кеш).

**Важно:** вручную — только для **быстрой итерации**. Регулярно пересобирай ZIP, чтобы не забыть зависимость.
