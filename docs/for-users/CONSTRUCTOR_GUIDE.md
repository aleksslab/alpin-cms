# Работа с конструктором страниц

## 🎯 Что такое конструктор

**Конструктор** — визуальный редактор содержимого страницы. Состоит из **трёх уровней:**

```
Страница
 └── Ряд (row)          ← горизонтальная полоса
      └── Колонка (col)  ← вертикальный блок внутри ряда
           └── Модуль (module)  ← конкретный блок контента
```

**Пример:**
```
Страница "Главная"
 ├── Ряд 1: [Hero на всю ширину]
 ├── Ряд 2: [Колонка 1/2: Text] [Колонка 1/2: Image]
 └── Ряд 3: [Колонка 1/3: Cards] [Колонка 1/3: Cards] [Колонка 1/3: Cards]
```

---

## 🚀 Как открыть конструктор

1. **Страницы** → **Редактировать** (карандаш) или **Создать страницу**.
2. В форме редактирования — **секция «Конструктор страницы»** (аккордеон).
3. Клик по заголовку — раскрывается.

**Интерфейс:**
- **Шаблон** — выбор (full-width, sidebar-left, sidebar-right, boxed).
- **Чекбоксы** — «Показывать глобальный хедер», «Показывать глобальный футер».
- **Зоны** — в зависимости от шаблона (main, sidebar-left, sidebar-right, hero).
- **Кнопка «Предпросмотр»** — открывает страницу в новой вкладке.

---

## 🏗 Работа с рядами

### Добавить ряд

В **зоне** (main, sidebar-left, sidebar-right) — кнопка **«Добавить ряд»**.

### Редактировать ряд

В шапке ряда:
- **ID** — опционально (для якоря `#id`).
- **Класс** — Tailwind-классы (например, `bg-slate-50 my-4`).
- **Колонок: N** — счётчик.

### Переместить ряд

Кнопки **↑**/**↓** в шапке.

### Удалить ряд

Кнопка **🗑** в шапке. **Удалит ряд со всеми колонками и модулями**.

---

## 🧱 Работа с колонками

### Добавить колонку

В шапке ряда — кнопка **«Колонка»**.

### Ширина колонки

Кнопки **◀**/**▶** рядом с шириной. **11 вариантов:**
```
w-2/12, w-3/12, w-4/12, w-5/12, w-6/12,
w-7/12, w-8/12, w-9/12, w-10/12, w-11/12, w-full
```

**Пример:** `w-6/12 + w-6/12` = 2 колонки пополам.

### ID и класс колонки

- **ID** — опционально.
- **Класс** — Tailwind (`bg-white p-4 border`).

### Удалить колонку

Кнопка **✕**. **Удалит все модули внутри**.

---

## 🧩 Работа с модулями

### Добавить модуль

**Вариант 1:** В шапке ряда — кнопка **«Модуль»** (добавит в последнюю колонку).
**Вариант 2:** Внутри колонки — кнопка **«Добавить модуль»**.

**Откроется модалка** с выбором модуля:
- Превью, название, описание.
- Клик по модулю → добавлен.

### Настройка модуля

Клик по **иконке ✏️** в карточке модуля → откроется модалка с формой настроек.

**Форма** — **генерируется** из `admin/module.php` **самого** **модуля**.

**После** **заполнения** — **«Сохранить»** → настройки **сохранены** **в** `data` **модуля**.

### Удалить модуль

Кнопка **🗑** в карточке.

### Переместить модуль

**Между** **колонками** — **нет** (**надо** **удалить** **и** **добавить**).

**Внутри** **колонки** — **порядок** = **порядок** **добавления**.

---

## 📄 Сохранение страницы

**Кнопка** **«Сохранить** **изменения»** **внизу** **формы** **страницы** (**вне** **конструктора**).

**Что** **сохраняется:**
- **Rows** **с** **колонками** **и** **модулями** **в** `data/pages/{id}.json`.
- **Meta** **страницы** (**title, slug, status, meta**).
- **Настройки** **модулей** (**в** `data` **каждого** **модуля**).

**Автосохранение** — **нет**. **Не** **забудь** **нажать** **«Сохранить»**.

## 🎨 Типичные сценарии

### Простая страница «О нас»

1. **Создай** **страницу** `about`.
2. **Шаблон** = `full-width`.
3. **Ряд 1:** Hero (заголовок, подзаголовок).
4. **Ряд 2:** Text (описание).
5. **Ряд 3:** Stats (счётчики).
6. **Сохрани** → **Опубликуй**.

### Лендинг с формой

1. **Создай** **страницу** `landing`.
2. **Ряд 1:** Hero.
3. **Ряд 2:** 2 колонки — слева **Text**, справа **Lead-form**.
4. **Ряд 3:** FAQ.
5. **Ряд 4:** Contacts (форма + карта).
6. **Сохрани**.

### Многостраничник

1. **Создай** **страницы** `about`, `services`, `contacts`.
2. **Создай** **меню** `header_main` → **пункты** **на** **эти** **страницы**.
3. **Назначь** **меню** **главным**.
4. **Готово** — **навигация** **работает** **во** **всех** **шаблонах**.

## 🎯 Советы

### Классы Tailwind

**Полезные** **классы** **для** **ряда**/**колонки**:

| Класс | Что делает |
|-------|-----------|
| `bg-slate-50` | Светло-серый фон |
| `bg-white` | Белый фон |
| `my-4` | Отступ сверху/снизу |
| `py-8` | Внутренний отступ по вертикали |
| `container` | Центрированный контейнер |
| `mx-auto` | Центрирование по горизонтали |
| `text-center` | Текст по центру |
| `border` | Граница |
| `rounded-xl` | Скруглённые углы |
| `shadow-lg` | Тень |

**Полный** **список** — [tailwindcss.com/docs](https://tailwindcss.com/docs).

### Проверка на разных устройствах

**После** **сохранения** — **открой** **страницу** **на** **фронте**:
- **Desktop** (**> 1024px**) — **полная** **ширина**.
- **Tablet** (**768-1024px**) — **проверь** **адаптивность**.
- **Mobile** (**< 768px**) — **всё** **должно** **умещаться**.

**Если** **модуль** **«ломается»** — **проверь** **его** **настройки** (**класс** **колонки** **может** **быть** **не** **адаптивный**).

### Предпросмотр

**Кнопка** **«Предпросмотр»** **в** **конструкторе** — **открывает** **страницу** **в** **новой** **вкладке** **с** `?preview=1`.

**Превью** **показывает** **страницу** **до** **публикации** (**даже** **если** **status = draft**).

**НО** — **не** **все** **модули** **работают** **в** **превью** (**некоторые** **требуют** **сохранения**).

## ⚠️ Частые ошибки

### Модуль не отображается

**Причины:**
- **Не** **распакован** — **открой** **Управление** **модулями** → **Распаковать**.
- **Пустые** **обязательные** **поля** — **открой** **настройки** **модуля**.
- **Ошибка** **в** **данных** — **проверь** `data/pages/{id}.json`.

### Съехала вёрстка

**Причины:**
- **Классы** **конфликтуют** — **упростить**.
- **Ширина** **колонок** **не** **суммируется** **в** `12/12` — **проверь**.
- **Модуль** **имеет** **свою** **вёрстку** — **учитывай**.

### Модуль дублируется

**Причина:** **оставлен** **дважды** **в** **одной** **колонке**/**рядах** — **проверь** **структуру**.
