# Установка AlPin CMS

## 📋 Требования

### Обязательные

- **PHP** 7.4 или выше (рекомендуется 8.1+)
  - Расширения: `json`, `mbstring`, `openssl`, `zip`, `fileinfo`
- **Apache** 2.4+ с модулями:
  - `mod_rewrite` (ЧПУ)
  - `mod_headers` (security-заголовки)
  - `mod_authz_core` (защита директорий)
- **Права на запись** для папок:
  - `data/`
  - `config/data/`
  - `cache/`
- **~50 МБ** свободного места на диске

### Опциональные

- **HTTPS** (обязательно для прода)
- **`mod_deflate`** (gzip-сжатие)
- **`mod_expires`** (кеширование статики на клиенте)

### Проверка требований

Открой в браузере `info.php` (создай временно) с содержимым:

```php
<?php phpinfo();
```

**Проверь:**
- `PHP Version` ≥ 7.4
- `Loaded Extensions`: json, mbstring, openssl, zip, fileinfo
- `Server API`: Apache
- `upload_max_filesize` ≥ 10M
- `post_max_size` ≥ 10M
- `memory_limit` ≥ 128M

**После проверки — удали `info.php`.**

## 🚀 Шаги установки

### 1. Скачай и распакуй архив

Распакуй архив в **корень сайта** (обычно `public_html/`, `www/`, `htdocs/`).

**Структура должна получиться:**
```
твой-сайт/
├── index.php
├── .htaccess
├── config/
├── data/
├── cache/
├── modules/
├── templates/
├── css/
├── js/
└── ...
```

### 2. Настрой права доступа

**Linux/macOS** (через SSH):

```bash
cd /path/to/site
chmod -R 755 data/ config/data/ cache/
chmod 644 data/settings.json config/data/*.json
```

**На хостинге** — через панель управления (ISPmanager, cPanel, Plesk, DirectAdmin).

**Папки, требующие записи:**
- `data/` — пользовательские данные
- `data/pages/` — страницы
- `data/menus/` — меню
- `data/logs/` — логи
- `config/data/` — системные данные
- `cache/` — кеш страниц и ассетов
- `cache/pages/`
- `cache/assets/`
- `images/` — загруженные картинки
- `css/` и `js/` — если включена минификация

### 3. Проверь `.htaccess`

Убедись, что в корне сайта есть `.htaccess` (может быть скрыт).  
**На Linux** — включи показ скрытых файлов в файловом менеджере.

**Содержимое `.htaccess`** (минимально):
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^(.*)$ index.php [QSA,L]
</IfModule>

Options -Indexes
```

**Если `.htaccess` не работает** (ЧПУ не работает, все URL открывают главную) — проверь:
- В `httpd.conf` или в настройках хостинга: `AllowOverride All` для директории сайта.
- `mod_rewrite` включён.

### 4. Настрой подключение к сайту

Открой в браузере:
```
https://твой-сайт/config/index.php
```

**Ожидаешь увидеть форму логина** (не 404, не 500).

**Если 500** — проверь:
- Права на `config/data/` (`755`).
- Версию PHP (`php -v` или `info.php`).
- Логи Apache (`error.log`).

### 5. Создай первого администратора

На форме логина нажми **«Конфигурация ключей»** (внизу).

**Введи пароль** (сложный, 12+ символов).

**Нажми «Сгенерировать ключ»** — получишь хеш вида:
```
$2y$10$abcdef...XYZ
```

**Скопируй хеш.**

**Открой** `config/data/credentials.json` (через FTP или файловый менеджер хостинга).

**Замени содержимое на:**
```json
{
    "login": "admin",
    "password_hash": "$2y$10$abcdef...XYZ"
}
```

**ВАЖНО:** `login` — придумай **свой** (не `admin`). Пароль **не сохраняй** в открытом виде.

**Сохрани файл.**

**Вернись на форму логина** и войди с логином и паролем.

### 6. Первоначальная настройка

**После первого входа:**

1. **Настройки сайта** → **Контактная информация:**
   - Название сайта
   - Телефон
   - Email
   - Адрес
   - Слоган

2. **Внешний вид** → **Цветовая схема:**
   - Основной цвет
   - Цвет hover
   - Фон страницы, карточек, секций
   - Цвета текста и границ

3. **Визуальные элементы:**
   - Логотип (загрузи через медиа-менеджер)
   - Favicon

4. **Хедер и футер:**
   - Вариант хедера (`default`, `centered`, `minimal`, `with-cta`)
   - Вариант футера (`default`, `minimal`, `dark`, `light`)
   - Фиксация хедера
   - Бургер-меню

5. **SEO:**
   - Meta Title, Description, Keywords
   - OG Title, Description, Image, URL
   - Twitter Title, Description, Image

6. **Создай главную страницу:**
   - **Страницы** → **Создать страницу**
   - Title: `Главная`
   - Slug: **оставь пустым**
   - Добавь модули через конструктор
   - Опубликуй

7. **Создай меню:**
   - **Меню** → **Создать меню**
   - Добавь пункты (страницы, ссылки)
   - Назначь главным (звёздочка)

### 7. Проверь работу

**Открой фронт** `https://твой-сайт/`:
- Главная отображается
- Меню работает
- Модули рендерятся
- Хедер/футер на месте

**Если что-то не так:**
- Очисти кеш: **Настройки** → **Кеширование** → **Очистить весь кеш**
- Проверь `data/logs/admin.log`
- Проверь `error.log` Apache

## 🔐 Настройка безопасности

**Сразу после установки** — **обязательно**:

### 1. Смени логин с `admin`

**Безопасность** → **Учётная запись** → **Логин** = свой уникальный.

### 2. Установи сложный пароль

**Минимум** 16 символов, **буквы** + **цифры** + **спецсимволы**.

### 3. Настрой Anti-Brute Force

**Безопасность** → **Параметры блокировки**:
- **Порог временного бана**: 5 попыток
- **Длительность таймера**: 15 минут
- **Порог вечной блокировки**: 3 бана
- **Окно отслеживания**: 24 часа
- **Таймаут сессии**: 20 минут

### 4. Включи HTTPS

**Если хостинг поддерживает**:
- Получи SSL-сертификат (Let's Encrypt — бесплатно).
- Настрой редирект HTTP → HTTPS.

**После включения HTTPS:**
- В `config/config.php` — `cookie_secure` уже автоматически `1` (по `$_SERVER['HTTPS']`).

### 5. Отключи DEBUG

**В** `config/config.php`:
```php
define('DEBUG_SITE', false);
define('DEBUG_ADMIN', false);
```

**Или** — **удали** **строки** `define('DEBUG_*', true)`.

### 6. Ограничь доступ к админке

**Опционально** — **по IP**:

В `config/.htaccess` **добавь**:
```apache
<RequireAll>
    Require ip 1.2.3.4
    Require ip 5.6.7.8
</RequireAll>
```

## 🔄 Обновление CMS

**Перед обновлением:**
1. **Сделай бэкап:** **Резервное копирование** → **Запустить**.
2. **Скачай бэкап** на компьютер.

**Обновление:**
1. **Скачай** новую версию.
2. **Распакуй** поверх старой (файлы `config/`, `modules/`, `templates/`, `css/`, `js/`, `index.php`, `.htaccess`).
3. **НЕ трогай**:
   - `data/` — пользовательские данные.
   - `config/data/` — настройки, credentials.
   - `cache/` — кеш (можно очистить).
4. **Очисти кеш** в админке.
5. **Проверь** работоспособность.

## ❓ Возможные проблемы

### 404 на всех страницах кроме главной

**Причина:** `.htaccess` не работает.

**Решение:**
- Проверь `AllowOverride All` в Apache.
- Проверь `mod_rewrite` включён.
- Перезапусти Apache.

### 500 Internal Server Error

**Причина:** права на `config/data/`, `cache/`, `data/`.

**Решение:**
```bash
chmod 755 data/ config/data/ cache/
```

### Логин не работает

**Причина:** неверный хеш в `credentials.json`.

**Решение:**
1. Перегенерируй хеш через «Конфигурация ключей».
2. Убедись, что в `credentials.json` точно `login` и `password_hash`.
3. Проверь, что `config/data/.pepper` существует и доступен.

### Кеш не сбрасывается

**Решение:**
- **Настройки** → **Кеширование** → **Очистить весь кеш**.
- **Или** — удали вручную `cache/pages/*.html` и `cache/assets/*`.
