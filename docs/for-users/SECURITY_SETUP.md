# Настройка безопасности на проде

**Чек-лист** **перед** **запуском** **сайта** **в** **продакшен**.

---

## 🔒 1. HTTPS

**Обязательно** **для** **прода.**

### Получить SSL-сертификат

**Бесплатно** — **Let's Encrypt**:
- **Через** **панель** **хостинга** (**ISPmanager**, **cPanel**, **Plesk**) — **1** **клик**.
- **Через** **Certbot** (**SSH**):
  ```bash
  certbot --apache -d твой-сайт.com -d www.твой-сайт.com
  ```

### Настроить редирект HTTP → HTTPS

**В** **корневой** `.htaccess` **добавь**:
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{HTTPS} off
    RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</IfModule>
```

### Проверка

- **Открой** `http://твой-сайт.com` → **редирект** **на** `https://`.
- **DevTools** → **Security** → **зелёный** **замок**.

### После HTTPS

**В** `config/config.php` — **проверь**:
```php
$isHttps = (!empty($_SERVER['HTTPS']) && $_SERVER['HTTPS'] !== 'off')
        || (!empty($_SERVER['HTTP_X_FORWARDED_PROTO']) && $_SERVER['HTTP_X_FORWARDED_PROTO'] === 'https');
ini_set('session.cookie_secure', $isHttps ? 1 : 0);
```
**Уже** **настроено** **автоматически**. ✅

## 🔐 2. Доступы администратора

### Смени логин

**Безопасность** → **Учётная запись** → **Логин** = **уникальный** (**не** `admin`).

### Сложный пароль

**Минимум** 16 символов:
- **Заглавные**/**строчные** **буквы**.
- **Цифры**.
- **Спецсимволы** (`!@#$%^&*`).

**Пример:** `My$ecureP@ss2025!xYz`.

### Храни в менеджере паролей

**Bitwarden**, **1Password**, **KeePass** — **не** **в** **блокноте**.

## 🧱 3. Anti-Brute Force

**Безопасность** → **Параметры** **блокировки:**

| Параметр | Рекомендуемое |
|----------|---------------|
| **Порог временного бана** | 5 попыток |
| **Длительность таймера** | 15 минут |
| **Порог вечной блокировки** | 3 бана |
| **Окно отслеживания** | 24 часа |
| **Таймаут сессии** | 20 минут |

**Журнал** **блокировок** — **проверяй** **раз** **в** **неделю**.

## 🐛 4. Отключи DEBUG

**В** `config/config.php`:
```php
define('DEBUG_SITE', false);
define('DEBUG_ADMIN', false);
```

**Или** **удали** **строки** `define('DEBUG_*', true)`.

**Проверка:**
- **Специально** **вызови** **ошибку** (**например**, **запроси** **несуществующий** **файл**).
- **Ожидание:** **белая** **страница** **или** **404**, **без** **stack** **trace**.

## 📁 5. Права доступа (CHMOD)

### Стандартные

| Папка | Права |
|-------|-------|
| `data/` | `755` |
| `config/data/` | `755` |
| `cache/` | `755` |
| `images/` | `755` |
| `css/`, `js/` | `755` |

| Файл | Права |
|------|-------|
| Все `.php` | `644` |
| Все `.json` | `644` |
| Все `.html` | `644` |

### Команда

```bash
find . -type d -exec chmod 755 {} \;
find . -type f -exec chmod 644 {} \;
chmod 755 data/ config/data/ cache/
```

### Проверка

**Убедись**, **что** **папки** **доступны** **на** **запись** **PHP**:
- **Сохрани** **настройки** **в** **админке**.
- **Если** **ошибка** — **права** **неверные**.

## 🚫 6. Защита директорий (.htaccess)

**Проверь** **наличие** `.htaccess` **в**:

| Директория | Содержимое |
|-----------|-----------|
| `config/` | `RewriteEngine Off`, `Options -Indexes` |
| `config/data/` | `Require all denied` |
| `config/backups/` | `Require all denied` |
| `data/` | `Require all denied` |
| `cache/` | `Require all denied` (**кроме** `.css`/`.js`) |
| `modules/` | `<FilesMatch "\.php$">` — **denied** |
| `templates/` | `<FilesMatch "\.php$">` — **denied** |
| `images/` | `<FilesMatch "\.php$">` — **denied** |

**Это** **уже** **сделано** **в** **CMS** **автоматически** **или** **при** **установке**. ✅

**Проверка:**
- `https://твой-сайт/config/data/credentials.json` — **403**.
- `https://твой-сайт/data/settings.json` — **403**.
- `https://твой-сайт/cache/pages/home.html` — **403**.
- `https://твой-сайт/modules/hero.php` — **403**.

## 🛡 7. Security-заголовки

**В** **корневом** `.htaccess`:
```apache
<IfModule mod_headers.c>
    Header always set X-Content-Type-Options "nosniff"
    Header always set X-Frame-Options "SAMEORIGIN"
    Header always set Referrer-Policy "strict-origin-when-cross-origin"
    Header always set Permissions-Policy "geolocation=(), microphone=(), camera=()"
    Header unset X-Powered-By
</IfModule>
```

**Уже** **в** **CMS**. ✅

**Проверка:** **DevTools** → **Network** → **Response Headers**.

## 🌐 8. Ограничь доступ к админке

### По IP (опционально)

**В** `config/.htaccess`:
```apache
<RequireAll>
    Require ip 1.2.3.4
    Require ip 5.6.7.8
</RequireAll>
```

### Через Basic Auth (дополнительный слой)

**В** `config/.htaccess`:
```apache
AuthType Basic
AuthName "Admin Panel"
AuthUserFile /path/to/.htpasswd
Require valid-user
```

**Создать** `.htpasswd`:
```bash
htpasswd -c /path/to/.htpasswd admin
```

## 💾 9. Регулярные бэкапы

**Резервное** **копирование** → **Виртуальный** **крон** (**24ч**).

**Рекомендация:** **скачивай** **бэкапы** **на** **локальный** **компьютер** **раз** **в** **неделю**.

**Место** **хранения** **бэкапов:**
- **Вне** **сайта** (**относительный** **путь** `../backups/`).
- **Или** **абсолютный** `/home/user/backups/`.
- **НЕ** **в** `config/backups/` (**попадёт** **в** **следующий** **бэкап** — **рекурсия**).

## 🔍 10. Мониторинг

### Логи CMS

**Логи** **системы** → **проверяй** **раз** **в** **неделю**:
- **CRITICAL**/**ERROR** — **сразу** **реагируй**.
- **WARNING** — **проверяй**.
- **Auth_failed** — **много** **попыток** = **атака** → **IP** **в** **бан**.

### Логи Apache

**`access.log`** — **подозрительные** **запросы**.
**`error.log`** — **ошибки** **PHP**/**Apache**.

### Внешние сервисы

- **UptimeRobot** — **мониторинг** **доступности**.
- **Sucuri**/**Cloudflare** — **защита** **от** **DDoS**.
- **SecurityHeaders.com** — **проверка** **заголовков**.

## 🚨 Что делать при инциденте

### Подозрение на взлом

1. **Смени** **пароль** **админа**.
2. **Проверь** **логи** **на** **странные** **действия**.
3. **Скачай** **бэкап** **на** **компьютер**.
4. **Проверь** **файлы** **на** **изменения** (**diff** **с** **оригиналом**).
5. **Проверь** `config/data/.pepper`, `credentials.json` — **не** **менялись**?
6. **Проверь** **загруженные** **файлы** **в** `images/` — **нет** **ли** **PHP**?
7. **Восстанови** **из** **бэкапа** **если** **нужно**.

### DDoS

- **Cloudflare** — **прокси** **через** **них** (**скроет** **IP**).
- **Fail2ban** — **автобан** **по** **логам**.
- **Rate limiting** — **в** **nginx**/**Apache** **mod_ratelimit**.
