# FAQ и решение проблем

## 🔧 Установка и настройка

### 500 Internal Server Error при открытии сайта

**Причины:**
- **Неверные** **права** **на** `config/data/`, `cache/`, `data/`.
- **Старая** **версия** **PHP** (< 7.4).
- **Ошибка** **в** `.htaccess`.

**Решение:**
```bash
chmod 755 data/ config/data/ cache/
```
**Проверь** `error.log` **Apache** — **там** **будет** **конкретная** **ошибка**.

### 404 на всех страницах кроме главной

**Причина:** `.htaccess` **не** **работает** (**mod_rewrite** **выключен** **или** `AllowOverride None`).

**Решение:**
- **В** `httpd.conf` — `AllowOverride All` **для** **директории** **сайта**.
- **Проверь** **включён** **ли** `mod_rewrite` (**в** **настройках** **Apache**).
- **Перезапусти** **Apache**.

### Логин не работает

**Причины:**
- **Неверный** **пароль**.
- **Повреждён** `credentials.json`.
- **Отсутствует** `.pepper`.

**Решение:**
1. **Перегенерируй** **хеш** **через** **«Конфигурация** **ключей»**.
2. **Обнови** `config/data/credentials.json`.
3. **Проверь** **наличие** `config/data/.pepper` (**не** **удаляй**!).
4. **Очисти** **cookies** **браузера** (`PHPSESSID`).
5. **Попробуй** **в** **режиме** **инкогнито**.

### Кеш не сбрасывается

**Решение:**
- **Настройки** **сайта** → **Кеширование** → **Очистить** **весь** **кеш**.
- **Вручную**: **удали** `cache/pages/*.html` и `cache/assets/*`.
- **Проверь** **права** **на** `cache/` (`755`).

### Изменения в админке не отображаются на фронте

**Причина:** **кеш** **включён**.

**Решение:**
- **Очисти** **кеш** **в** **админке**.
- **Или** — **выключи** **кеширование** **на** **время** **разработки**.
- **Проверь** `cache/pages/` — **есть** **там** **старая** **версия**?

## 🎨 Модули и конструктор

### Модуль не отображается на странице

**Причины:**
- **Модуль** **не** **распакован** (**статус** «**в** **архиве**»).
- **Пустые** **обязательные** **поля**.
- **Ошибка** **в** **данных** **модуля**.
- **Кеш** **показывает** **старую** **версию**.

**Решение:**
1. **Управление** **модулями** → **проверь** **статус** → **«Распаковать»**.
2. **Открой** **настройки** **модуля** **в** **конструкторе** — **заполни** **обязательные** **поля**.
3. **Очисти** **кеш**.
4. **Открой** `data/pages/{id}.json` — **проверь** **есть** **ли** `type` **модуля**.

### Модуль «съехал» / вёрстка сломалась

**Причины:**
- **Конфликт** **Tailwind-классов**.
- **Ширина** **колонок** **не** **суммируется** **в** `12/12`.
- **Модуль** **имеет** **свою** **вёрстку**, **конфликтует** **с** **соседями**.

**Решение:**
- **Упростить** **классы** **ряда**/**колонки**.
- **Проверить** **сумму** **ширины** **колонок** (**например**, `w-6/12 + w-6/12`).
- **Проверить** **на** **разных** **разрешениях**.

### Не могу загрузить модуль (ZIP)

**Причины:**
- **Размер** > 10 МБ.
- **Отсутствует** `manifest.json`.
- **Формат** не ZIP.
- **`manifest.id`** **невалидный** (**только** **a-z**, **0-9**, `-`, `_`).

**Решение:**
- **Проверь** **структуру** **ZIP**.
- **Уменьши** **размер** (**сожми** **картинки**).
- **Проверь** `manifest.json` **на** **валидность**.

### Модуль «зависает» при добавлении

**Причина:** **модуль** **не** **распакован**, **CMS** **пытается** **распаковать**.

**Решение:** **подожди** 5-10 **сек**, **обнови** **страницу**.

## 🎨 Дизайн

### Цвета не меняются

**Причина:** **кеш** **CSS** **в** **браузере**.

**Решение:**
- **Ctrl+F5** (**жёсткое** **обновление**).
- **Очисти** **кеш** **в** **админке**.
- **Проверь** **в** `index.php` — **цвета** **в** `<style>` **обновлены**?

### Логотип не отображается

**Причины:**
- **Неверный** **путь**.
- **Файл** **не** **загружен**.
- **Формат** **не** **поддерживается**.

**Решение:**
- **Проверь** **путь** **в** **настройках**.
- **Загрузи** **через** **медиа-менеджер**.
- **Используй** PNG/SVG.

### Шрифт иконок не работает

**Причины:**
- **Отсутствует** `fonts/lucide.css` **или** `fonts/brands.svg`.
- **Кеш** **браузера**.

**Решение:**
- **Проверь** **наличие** **файлов**.
- **Ctrl+F5**.
- **Открой** **DevTools** → **Network** → **проверь** **404**.

## 🔐 Безопасность

### Меня заблокировало (мой IP в бане)

**Решение:**
1. **Зайди** **с** **другого** **IP** (**мобильный** **интернет**).
2. **Безопасность** → **Журнал** **блокировок** → **найди** **свой** **IP**.
3. **Нажми** **«Разблокировать»**.

**Или** — **через** `config/data/login_attempts.json`:
- **Удали** **свой** **IP** **из** `attempts`.
- **Сохрани** **файл**.

### CSRF-ошибка при сохранении

**Причины:**
- **Сессия** **истекла**.
- **Cookie** **заблокированы**.
- **Открыл** **сайт** **в** **нескольких** **вкладках**.

**Решение:**
- **Обнови** **страницу** (**Ctrl+F5**).
- **Залогинься** **снова**.
- **Используй** **одну** **вкладку** **для** **админки**.

### Warning: preg_match / Undefined variable

**Причина:** `DEBUG_SITE`/`DEBUG_ADMIN = true`.

**Решение:**
- **На** **проде** — `DEBUG_* = false`.
- **На** **локалке** — **проверь** **лог** `data/logs/php_errors.log`.

## 📦 Бэкапы

### Бэкап не создаётся

**Причины:**
- **Мало** **места** **на** **диске**.
- **Неверный** `storage_path`.
- **Нет** **прав** **на** **запись**.

**Решение:**
- **Проверь** **свободное** **место** (**Резервное** **копирование** → **статистика**).
- **Проверь** **путь**.
- **Проверь** **права** **CHMOD** (`755`).

### Восстановление «зависло»

**Причина:** **большой** **сайт** (**> 10 000** **файлов**), **PHP** **timeout**.

**Решение:**
- **Увеличь** `max_execution_time` **до** 600.
- **Увеличь** `memory_limit` **до** 512M.
- **Используй** **системный** **крон** **для** **бэкапов**.

### Не могу расшифровать бэкап

**Причина:** **неверный** **пароль** **или** **повреждён** **архив**.

**Решение:**
- **Проверь** **пароль** (**тот** **же**, **что** **при** **создании**).
- **Попробуй** **открыть** **в** **7-Zip**/**WinRAR**.
- **Если** **архив** **повреждён** — **восстанови** **из** **другого** **бэкапа**.

## ⚡ Производительность

### Сайт работает медленно

**Причины:**
- **Кеш** **выключен**.
- **Много** **модулей** **на** **странице**.
- **Не** **включена** **минификация**.
- **Хостинг** **слабый**.

**Решение:**
- **Включи** **кеширование** (**Настройки** → **Кеширование**).
- **Включи** **минификацию** (**Настройки** → **Минификация**).
- **Убери** **лишние** **модули**.
- **Включи** **объединение** **ассетов**.

### Админка тормозит

**Причина:** **много** **страниц** **в** **списке**.

**Решение:**
- **Установи** `per_page = 25` (**по** **умолчанию**).
- **Используй** **поиск**/**фильтры**.

### Конструктор «зависает» при 20+ модулях

**Причина:** **большой** **JSON** **в** `constructor-data`.

**Решение:**
- **Разбей** **страницу** **на** **несколько**.
- **Сохрани** **промежуточно**.
